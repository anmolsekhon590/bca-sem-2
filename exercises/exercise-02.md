# Exercise 02 — Control Structures

---

## 1. Grade Calculator
Ask the user for a score (0-100). Use `if/else if/else` to print the grade.

```
90-100 → A
80-89  → B
70-79  → C
60-69  → D
below  → F
```

Expected output:
```
Enter score: 85
Grade: B
```

---

## 2. Day of the Week
Ask the user for a number (1-7). Use a `switch` to print the day name. Handle invalid input with `default`.

Expected output:
```
Enter day number: 3
Wednesday
```
```
Enter day number: 9
Invalid day
```

## 3. Multiplication Table
Ask for a number. Use a `for` loop to print its multiplication table up to 10.

Expected output:
```
Enter a number: 5
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

## 4. Sum of Natural Numbers
Ask the user for a number `n`. Use a `while` loop to calculate the sum of all numbers from 1 to n.

Expected output:
```
Enter n: 10
Sum: 55
```

## 5. Input Validation with do-while
Keep asking the user to enter a number between 1 and 10 until they get it right. Use a `do-while` loop.

Expected output:
```
Enter a number (1-10): 15
Invalid, try again.
Enter a number (1-10): 0
Invalid, try again.
Enter a number (1-10): 7
Got it: 7
```

## 6. FizzBuzz
Loop from 1 to 20. Print:
- `Fizz` if divisible by 3
- `Buzz` if divisible by 5
- `FizzBuzz` if divisible by both
- The number otherwise

> Hint: check divisible by both first.
